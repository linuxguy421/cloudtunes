# Control-plane onboarding API (Phase 2)

This branch builds on the isolated control-plane foundation. Run only
`compose.control-plane.dev.yaml`; do not combine it with the existing streaming
stack.

## First administrator

1. Start the isolated development stack and apply migrations.
2. Registration is disabled by default. For a one-time bootstrap only, set `CLOUDTUNES_PUBLIC_REGISTRATION_ENABLED=true` in the root Compose `.env` file and recreate the control-plane services.
3. Register the intended administrator through `POST /api/v1/register`, then immediately set the flag back to `false` and recreate the services.
4. Promote that existing account from the control-plane container:

```sh
docker compose -f compose.control-plane.dev.yaml exec control-plane \
  php artisan cloudtunes:make-admin admin@example.test
```

The command fails if the email does not belong to an existing user. It does not
create a password or expose an unauthenticated admin-provisioning endpoint.

## Session-based API

These endpoints use Laravel's session authentication and the web middleware.
Browser clients must use the normal session cookie and CSRF protection.

- `POST /api/v1/register`: disabled by default (returns 404); it accepts `name`, `email`, `password`, and `password_confirmation` only while the explicit bootstrap flag is enabled. New accounts are pending approval.
- `POST /api/v1/login`: accepts `email` and `password`; returns the user's
  approval state and regenerates the session on success.
- `POST /api/v1/logout`: ends the current session.
- `PATCH /api/v1/admin/users/{user}/approval`: administrator-only; accepts
  `approval_status=approved` or `rejected`.
- `GET /api/v1/stations`: lists the current user's stations.
- `POST /api/v1/stations`: approved users and administrators can create a
  stopped, draft station by name. Slugs and mount paths are generated by the
  server.

Station creation does not start an audio process or claim that a stream is
playable. Real runtime integration, media upload/quota accounting, and
concurrent-running-station enforcement remain subsequent milestones. The
station quota is a concurrency limit and must be enforced when a station is
started, not merely when a stopped station record is created.
